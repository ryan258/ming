# Inputs

The business operation, request fields, response fields, trust boundaries, and compatibility needs.

# Method

Define request and response shapes, field constraints, authentication boundary, error envelope,
idempotency behavior, timeout behavior, and representative success and negative-path tests.

# Output

A framework-neutral contract followed by an implementation checklist. Avoid inventing deployment,
storage, or authentication choices not present in the brief.
