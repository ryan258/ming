# Ming Craft Rules

1. **Retrieve before prompting.** A specialist receives the smallest relevant capability slice, not
   the whole repository or codex.
2. **Never silently spend.** Live text routes must end in `:free` or use `openrouter/free`. A paid
   image route is separate and needs explicit per-image authorization before transport.
3. **Ephemeral means ephemeral.** Specialist definitions and working context are not persisted as
   reusable identities.
4. **Evidence before ROI theater.** Report observed tokens, latency, and operator-supplied estimated
   hours separately. Never present estimated labor value as measured savings.
5. **Degrade legibly.** Missing keys, rotating models, rate limits, invalid JSON, and unsupported
   features produce visible states with recovery guidance.
6. **Art serves the need.** Image prompts begin with communication purpose and audience, request one
   composition, default to no rendered text, and retain exact model/cost/digest provenance.
